# Placement Analytics & Candidate Tracking Dashboard

An interactive **Advanced Excel MIS dashboard** that tracks candidate placements across vocational training batches, built to give management a quick view of placement performance, hiring trends and batch-wise results.

## Overview

| Metric | Value |
|---|---|
| Candidates tracked | 1,146 |
| Training batches | 55 |
| Overall placement rate | 69.45% |
| Average placement salary | INR 13,234 |

**Placement rate logic:** Placed candidates divided by total batch capacity (55 batches x 30 students per batch = 1,650 seats).

## Key Features

- **KPI cards** for total placements, placement rate and average salary
- **Top hiring sectors** and employer-wise placement view
- **Gender-wise and batch-wise trends** shown with charts
- **Pivot Tables with multi-slicer filters** for Batch, Trade, Status and Employer
- **Data validation and cleaning** (duplicate removal, consistent status entries) for reliable reporting

## Tools Used

- Microsoft Excel: Pivot Tables, Pivot Charts, Slicers, Conditional Formatting, Data Validation
- Formulas: XLOOKUP, VLOOKUP, INDEX-MATCH, SUMIFS, COUNTIFS, IF/IFS

## How to Use

1. Download the Excel file from this repository.
2. Open it in Microsoft Excel (2016 or later; XLOOKUP needs Excel 365 / 2021).
3. Use the slicers on the dashboard sheet to filter by batch, trade, status or employer.
4. Refresh the Pivot Tables after adding new data (Data > Refresh All).
